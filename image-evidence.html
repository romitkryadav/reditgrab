Reddit image downloader test results

This page reports what one manual image lookup returned. It is a small compatibility check, not a claim that every Reddit post works or that downloads were saved on every device.

Manual image lookup

Checked October 26, 2026 in a desktop browser using the local preview of Reddit Downloader and a public Reddit link supplied for this check.

Test post: view the public Reddit post.

1 public post lookup4 image cards returnedFormats and dimensions displayed

What the tool returned

The post title shown by Reddit Downloader was “since someone demanded for the entire confrontation sequence of scout op inframe: bigboss.” The results contained one Reddit external-preview PNG and three Reddit-hosted JPEG files.

  • PNG preview: 719 × 376 pixels (served from external-preview.redd.it).
  • JPEG image 2: 1216 × 966 pixels (served from i.redd.it).
  • JPEG image 3: 1272 × 1261 pixels (served from i.redd.it).
  • JPEG image 4: 1179 × 2556 pixels (served from i.redd.it).

Scope and limits

The lookup confirmed that four image cards appeared and that their file labels and dimensions loaded. This check did not click Download or verify saved files, image quality against the uploader's original, mobile browsers, or other posts.

It was run on the local preview at 127.0.0.1:5502, so it does not confirm the currently deployed production version. Reddit posts and their image URLs can be changed, removed, or restricted after a check. A single post is not a representative success rate.

A result-quality correction

A separate built-in sample lookup returned Reddit's generic new-icon.png site icon as if it were the post image. The image lookup now filters that specific placeholder from post results and from the post-thumbnail fallback. The correction does not prove the sample post contains downloadable media.
